# TM.Common.Models

A collection of common models and base entities for TM applications.

## 📦 NuGet Package

This project is available as a NuGet package:

# BUILD PACKAGE
dotnet build -c Release

dotnet nuget push "bin\Release\TM.Common.Models.1.0.0.nupkg" --api-key <YOUR_API_KEY> --source https://api.nuget.org/v3/index.json
